# VtNote v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:test-driven-development`. Implement only the task assigned to you, run its focused tests, self-review, and commit the result.

**Goal:** Build a Windows-local web application that extracts Bilibili/YouTube/local subtitles, falls back from Volcengine cloud ASR to local faster-whisper, optionally translates and creates AI notes, and stores only compact text artifacts.

**Architecture:** A FastAPI/SQLAlchemy API and a separate durable SQLite worker share typed domain modules. React/TypeScript is built once and served by FastAPI. Source, ASR, translation, and note processors are explicit adapters; no plugin framework or in-memory task queue is introduced.

**Tech Stack:** Python 3.11 Conda, FastAPI, SQLAlchemy 2, SQLite WAL, Pydantic 2, httpx, yt-dlp, FFmpeg, faster-whisper, React, TypeScript, Vite, Vitest, pytest.

## Global Constraints

- Bind only to `127.0.0.1:8765`; same-origin UI, no permissive CORS.
- Code lives under `D:\Workspace\Project\VtNote`; durable data defaults to `D:\Workspace\Project\VtNote-data`; runtime media cache defaults to `D:\Workspace\Codex\cache\VtNote-runtime`.
- Never delete or modify the user's original media/subtitle file. App-owned cache enters a 24-hour recoverable trash area and every move/purge is logged.
- `transcript.json` is the immutable source transcript; SRT/VTT/TXT/Markdown are generated on demand.
- Native/manual subtitles precede cloud ASR; cloud ASR precedes local ASR only after a tested profile and upload consent.
- Volcengine flash ASR uses `X-Api-Key`, resource `volc.bigasr.auc_turbo`, JSON base64 audio, and no blind retry after ambiguous timeout.
- Translation and notes are independent downstream stages. Translation defaults off; notes default on only when a chat profile exists.
- Secrets use Windows Credential Manager through `keyring`; database/API/logs expose only `has_secret`.
- New behavior is developed test-first. No production behavior is added without observing a focused failing test.

---

### Task 1: Backend foundation and compact transcript core

Create the Python package, settings, SQLAlchemy models, migrations/bootstrap, canonical transcript/translation schemas, subtitle parsers, exporters, provider connection/profile services, and FastAPI CRUD/task/export endpoints. Include atomic artifact writes, strict local paths, keyring abstraction, CSRF/origin checks, and tests for every public behavior.

### Task 2: Durable worker and processing adapters

Implement SQLite leases/heartbeats/recovery, source probing and retrieval through yt-dlp/local files, Volcengine flash ASR eligibility/request/response mapping, local faster-whisper lazy loading, translation cue-ID validation, long-form note generation, stage retry/cancel semantics, and recoverable cache cleanup. External systems must be dependency-injected and contract-tested without live credentials.

### Task 3: React web interface

Create a minimal three-surface UI: create task, task/item details with exports and stage retry, and settings for connections/profiles/defaults. Show the exact remote-upload execution summary, warnings, progress, and secret presence without rendering secrets. Add component and API-client tests and produce a static build consumable by FastAPI.

### Task 4: Launcher, integration, security, and documentation

Add the Windows launcher/supervisor, environment lock files, first-run directory/model checks, static serving fallback, structured sanitized logs, end-to-end API/worker tests, installation/run documentation, sample configuration, and dependency/quality gate scripts. Verify restarts, cleanup, secret scans, URL allowlisting, and the no-audio-download subtitle path.

### Task 5: Whole-project review and release verification

Run backend tests, frontend tests, lint/type checks, production build, dependency probes, and a clean-start smoke test. Perform independent spec/security/code-quality review, fix all Critical/Important findings, update the implementation log, and prepare the branch for user integration without pushing or merging.
