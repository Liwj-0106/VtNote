# VtNote 暖调内容工作台 UI 设计

状态：设计基线，等待用户书面复核  
日期：2026-07-29  
适用范围：VtNote V1 React 桌面浏览器界面  
关联规格：[website-specification.md](../../website-specification.md)

## 1. 设计目标

VtNote 是面向个人学习、研究和内容整理的视频转录工具。界面的单一任务是让用户用最少的判断完成“添加来源、生成字幕、阅读或导出结果”，同时在真实发生云上传、计费或恢复操作时提供充分说明。

视觉参考 Claude 与 Anthropic 当前官网的暖色、中性、内容优先和低装饰气质，但不复制其标识、插图、组件细节或商标化表达。VtNote 的自身识别来自“时间线细线与时间码”这一转录语义，而不是模仿聊天产品。

设计必须满足：

- 浅色主题、简约、安静，适合长时间阅读字幕与笔记。
- 侧边栏可收起，交互参考现代桌面工具的稳定导航方式。
- 首屏只显示当前操作所需信息；高级处理、隐私和恢复信息按条件出现。
- 状态不只依赖颜色；所有主要操作可由键盘完成。
- 不添加营销首页、社区、账户、插件市场或批量控制台。

## 2. 采用方案与取舍

采用“暖调转录工作台”，不采用纯黑白文档界面或高密度管理后台。

选择理由：

- 暖米白和墨色正文降低长字幕阅读时的视觉刺激。
- 陶土色能表达时间码、选中态和提示，但不会把整个工具染成品牌橙。
- 收起式侧栏保留稳定导航，又能把宽度让给字幕和笔记。
- 渐进披露适合 V1 单来源任务，避免尚未添加来源时展示无意义的模型参数。

明确舍弃：

- 旧规格中的蓝色主色、固定顶栏、全局面包屑和常驻页脚。
- 每个信息块都套卡片、渐变背景、玻璃拟态和装饰性大标题。
- 用多枚徽章重复表达同一状态。
- 在没有云调用时常驻显示云服务、计费和授权说明。
- 以聊天气泡承载字幕或笔记。

## 3. 视觉系统

### 3.1 色彩令牌

| 令牌 | 值 | 用途 |
|---|---:|---|
| `canvas` | `#F7F5F0` | 应用主背景 |
| `sidebar` | `#EFECE6` | 展开或收起侧栏 |
| `surface` | `#FCFBF8` | 输入区、弹层和必要容器 |
| `surface-strong` | `#FFFFFF` | 需要从正文中抬升的菜单 |
| `ink` | `#262421` | 标题、正文、深色按钮 |
| `ink-secondary` | `#6F6A63` | 辅助说明 |
| `ink-tertiary` | `#8A857D` | 非关键元数据 |
| `terracotta` | `#C15F3C` | 时间码、选中线和重点提示 |
| `terracotta-strong` | `#8B3F29` | 可访问链接、焦点和强调文字 |
| `terracotta-soft` | `#E9DDD5` | 当前导航与柔和选中背景 |
| `border` | `#DDD9D2` | 分隔线和输入边界 |
| `success` | `#39705A` | 完成 |
| `warning` | `#8A5A18` | 计费、授权和可恢复警告 |
| `danger` | `#A33C32` | 失败和破坏性确认 |

正文、链接、按钮和状态组合必须在实际背景上满足 WCAG 2.2 AA。陶土色不直接作为白字大按钮背景；主要按钮使用 `ink` 背景和暖白文字，陶土色负责焦点、时间线和选中态。

### 3.2 字体

- 正文：`Segoe UI`, `Microsoft YaHei UI`, `Microsoft YaHei`, system-ui, sans-serif。
- 产品字标和少量英文展示文字：`Georgia`, `Noto Serif SC`, serif；中文页面标题仍使用正文栈。
- 时间码、任务 ID 和错误码：`Cascadia Mono`, `Consolas`, monospace。
- 不从公网加载字体。

字号：

- 页面标题：28px / 1.25 / 600。
- 区块标题：18px / 1.4 / 600。
- 正文和表单：16px / 1.55。
- 辅助文字：14px / 1.5。
- 时间码与元数据：13px / 1.4。

### 3.3 间距、边框与层级

- 使用 4px 基础网格，主要间距为 8、12、16、24、32 和 48px。
- 容器圆角为 12px；小控件为 8px；不要混用大量胶囊形状。
- 常规内容不用阴影。菜单和模态框只使用一层低对比阴影。
- 卡片只在信息确实需要独立边界时使用；同一阅读流优先用空白和细分隔线。
- 动效只用于侧栏收起、菜单出现和状态反馈，持续 150–220ms，并支持 `prefers-reduced-motion`。

## 4. 应用外壳与侧边栏

### 4.1 桌面结构

```text
┌────────────────┬─────────────────────────────────────────────┐
│ VtNote      «  │ 页面标题                         页面动作   │
│                │                                             │
│ ＋ 新建         │                                             │
│ ○ 任务          │                 主内容                      │
│                │                                             │
│ 最近任务        │                                             │
│ · 课程视频      │                                             │
│ · 产品访谈      │                                             │
│                │                                             │
│ ⚙ 设置          │                                             │
└────────────────┴─────────────────────────────────────────────┘
```

- 展开宽度 232px，收起宽度 64px。
- 收起按钮固定在产品字标同行；状态持久化到非敏感本机界面偏好。
- 收起后只显示图标，每个图标有 tooltip、`aria-label` 和可见焦点。
- 主导航只有“新建”“任务”“设置”。
- “最近任务”仅在展开时显示，最多五项；没有任务时整段隐藏。
- 设置固定在底部，不在顶部重复放置。
- 当前页面同时使用柔和背景、左侧陶土色短线和文字权重表达。
- 不保留全局顶栏、全局面包屑或常驻页脚。

### 4.2 响应式

- `>=1024px`：展开或收起的固定侧栏。
- `768–1023px`：默认收起为 64px。
- `<768px` 或 200% 缩放：侧栏变成覆盖式抽屉，关闭后主内容占满宽度。
- 抽屉打开时锁定背景滚动、圈定焦点，并可用 Escape 关闭。
- 375px 宽度不得出现页面级横向滚动。

## 5. 页面设计

### 5.1 新建任务

首屏只保留页面标题和一个来源输入区。

```text
新建任务

┌──────────────────────────────────────────┐
│ 粘贴 B 站或 YouTube 公开链接              │
│                                    添加  │
└──────────────────────────────────────────┘
  链接        本地视频        字幕文件
```

- 来源类型使用紧凑分段控件，不使用三张大卡片。
- URL 只有在用户点击“添加”后探测，不随输入自动请求。
- 文件输入显示文件名、大小和校验状态，不显示浏览器伪路径。
- 来源就绪后才出现“处理方式”：
  - 转录：自动、仅云端、仅本地。
  - 翻译：默认关闭；开启后显示目标语言和配置。
  - AI 笔记：开启后显示模板，其他字段继续按需展开。
- 页面底部只有一个主要动作“创建任务”。
- 若实际会上传音频，在主要动作上方显示一行可展开摘要：“将上传音频到腾讯云 · 可能计费 · 可改用本地”。没有上传时不显示。
- 版权和平台条款提醒使用一行辅助文字，不建立独立大卡片。

### 5.2 任务列表

- 页面标题右侧只有“新建任务”。
- 默认以安静的纵向列表展示，不使用数据表格或统计卡。
- 每行显示标题、来源、更新时间和一个聚合状态。
- 状态下方仅在运行中显示当前阶段，例如“正在生成转录”。
- 搜索和状态筛选放在同一工具行；筛选条件为空时不显示筛选摘要。
- 空状态只提供“新建任务”，不放装饰插图。

### 5.3 任务详情

宽屏采用正文与状态检查器两栏：

```text
标题                                             导出
来源 · 时长 · 创建时间

┌──────────────────────────────────┬──────────────┐
│ 字幕   AI 笔记   译文             │ 当前状态     │
│                                  │ 获取来源  ✓  │
│ 00:12  第一条字幕……               │ 生成转录  ●  │
│ 00:18  第二条字幕……               │ AI 笔记   ○  │
│                                  │              │
│                                  │ 停止任务     │
└──────────────────────────────────┴──────────────┘
```

- 主栏优先显示不可编辑的规范字幕；笔记和译文是并列标签页。
- 时间码左侧使用一条连续细线，当前或引用时间点以陶土色短刻度表示。这是全站唯一显著视觉签名。
- 字幕正文不使用聊天气泡，不给每条 cue 加卡片。
- 右栏宽度 280px，显示阶段、最新 attempt 和下一步动作；历史 attempt 默认折叠。
- 完成后右栏收缩为简短结果摘要，不持续占据注意力。
- 错误显示在对应阶段旁，并提供一个明确动作；原始供应商响应和敏感字段不可见。
- 小屏和 200% 缩放时右栏移到正文上方。

### 5.4 设置

- 使用单列分组列表：“运行环境”“云与 AI”“默认处理”“存储”。
- 设置概览只显示每组最重要的状态和一个进入动作。
- 连接详情中，SecretId/SecretKey 只显示“已保存/未保存”和“替换”，绝不回显。
- 固定 endpoint、地域、模型和内部参数使用只读摘要，不把不可编辑值伪装成输入框。
- 远程能力测试、上传授权与静态配置校验分开显示。
- 危险或不可逆操作放在页面末尾，并使用匹配风险的确认对话框。

### 5.5 首次就绪页

- 不使用欢迎营销页。
- 以紧凑检查列表显示必需能力和可选能力。
- 可用能力不因其他可选项缺失而被遮挡。
- 主要动作是“继续使用可用功能”；安装或修复动作与对应检查项相邻。

## 6. 内容精简规则

界面文字遵循“一个元素只做一件事”：

- 页面标题不在侧栏、顶栏和正文重复出现。
- 同一状态只出现一次；图标、颜色和文字共同表达，但不新增第二枚徽章。
- 技术值只在帮助判断或排错时展示。
- 默认隐藏模型上下文长度、温度、VAD、并发数和固定协议字段。
- “本地保存”“云上传”“可能计费”按任务真实路由显示，不作为每页常驻口号。
- 成功使用短句确认；失败说明发生了什么以及可执行的下一步。
- 不使用“100% 准确”“绝不计费”“完全私密”等不可验证承诺。

## 7. 组件边界

- `AppShell`：响应式侧栏、主内容和跳转主内容链接。
- `Sidebar`：主导航、最近任务和收起状态。
- `SourceComposer`：URL、媒体、字幕三种来源输入。
- `ProcessingOptions`：来源就绪后的渐进处理配置。
- `CloudDisclosure`：仅在真实云路由时显示上传、授权和计费摘要。
- `TaskListItem`：标题、来源、更新时间和聚合状态。
- `StageInspector`：阶段、attempt、错误和恢复动作。
- `TranscriptReader`：虚拟化 cue、时间线和可访问全文模式。
- `ResultTabs`：字幕、译文和 AI 笔记。
- `SettingsGroup`：单列设置摘要与进入动作。
- `InlineNotice`、`ConfirmDialog`、`SecretField`、`ExportMenu`：共享安全组件。

组件不读取密钥、不持久化任务业务状态，也不自行发起未由用户触发的有副作用请求。

## 8. 状态、错误和数据流

- 创建按钮在请求期间禁用并保持宽度，成功后导航到任务详情；刷新只执行 GET。
- 非终态任务自适应轮询，同一时刻只有一个在途 GET；终态停止轮询。
- 阶段没有可靠分母时不显示百分比。
- 云创建结果未知时显示“云任务可能已创建”，不提供普通的一键云重试。
- 可选翻译或笔记失败不遮盖字幕，详情显示“已完成，有警告”。
- 表单错误与字段相邻；全局错误只用于会话、服务不可用或未知故障。
- toast 仅确认跨页面成功，不承载必须长期可见的警告。

## 9. 无障碍和质量门槛

- 每页一个 `h1`，标题不跳级。
- 所有点击目标至少 44×44px，相邻目标间距至少 8px。
- 键盘可完成导航、来源输入、任务创建、标签页、导出、重试和设置。
- 侧栏、抽屉、菜单和模态框具备正确焦点管理。
- 状态由文字和形状共同表达，不只依赖颜色。
- 正文、控件、焦点和错误组合达到 WCAG 2.2 AA。
- 支持 375、768、1024、1440px 和 200% 缩放。
- 支持 `prefers-reduced-motion` 与 Windows 强制颜色模式。
- 前端不加载第三方字体、分析脚本或 CDN 运行代码。

## 10. 验收证据

实现完成时至少提供：

- 1440px 展开侧栏、1440px 收起侧栏、768px 和 375px 的页面截图。
- 新建任务、任务列表、运行中详情、完成详情、失败详情和设置的视觉回归。
- 键盘顺序、焦点恢复、抽屉焦点圈定和 Escape 行为测试。
- axe 或等价自动检查，加人工对比度与 200% 缩放检查。
- 侧栏状态持久化不包含任务、密钥、URL 或其他敏感数据的检查。
- 页面文本审计，证明旧蓝色令牌、重复顶栏、面包屑和常驻页脚已移除。

## 11. 实现边界

- 技术栈维持 React、TypeScript 和 Vite，由 FastAPI 同源提供生产静态文件。
- V1 只实现浅色主题；深色主题不进入本次范围。
- 图标使用同一套本地 SVG 线性图标，不使用 emoji 充当状态图标。
- 不为了视觉效果增加外部服务、账户系统、遥测、复杂动画或新的后端业务能力。
- 本设计覆盖并替代旧网站规格中的应用外壳、蓝色令牌、页面卡片密度和顶栏方案；业务、安全、状态机与数据合同继续以产品需求和技术决策为准。
