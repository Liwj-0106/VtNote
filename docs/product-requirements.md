# VtNote V1 产品需求文档

状态：当前实现基线
校准日期：2026-08-30
适用范围：Windows 本地版

## 1. 产品定义

VtNote 帮助用户把公开 B 站、抖音、YouTube 视频、本地音视频或已有字幕文件整理成可保存、检索和复用的字幕与笔记。产品采用本地工作区：任务、规范字幕和笔记保存在用户电脑，用户可按任务选择是否调用云 ASR 和大模型。

核心原则：

1. 字幕与 AI 笔记解耦；只选择字幕时不得调用大模型。
2. 平台字幕优先，没有可用字幕才进入 ASR。
3. 已完成成果不因后续阶段失败而丢失。
4. 密钥不进入数据库、任务快照、日志或浏览器持久化。
5. 对平台限制、云端费用和本地模型缺失给出明确状态，不静默绕过。

## 2. 目标用户与场景

- 需要整理课程、访谈、分享和会议录制的学习者或内容工作者。
- 希望保留时间戳字幕，而不是只得到不可追溯摘要的用户。
- 希望任务记录和文本成果保存在本机，并自行配置服务凭据的用户。

典型旅程：

1. 用户在设置中配置并验证腾讯云 ASR；需要笔记时再配置 TokenHub。
2. 用户粘贴公开 B 站、抖音、YouTube 单视频链接、B 站合集/列表链接或包含多个链接的分享文字，上传一个或多个本地音视频，或导入一个或多个 SRT、VTT、ASS、TXT 字幕。多链接先逐条预检；多文件逐个创建独立任务，单项失败不阻断其他有效项。
3. 用户在“设置 → 导出”中选择音频、原文和/或总结、分别选择格式，并通过系统文件夹选择器设置导出目录；默认目录为项目下 `exports/`。
4. 创建任务后进入内容库，查看当前阶段和进度。
5. 失败任务从内容库进入详情，查看云端/本地原因并选择重试方式。
6. 有可用成果时打开导出弹窗，下载已经生成的成果。

## 3. V1 范围

### 3.1 当前用户功能

| 能力 | 当前合同 |
|---|---|
| Bilibili 链接 | 公开、无需登录的单视频，以及 UP 主空间 `lists`/旧版 channel 合集或列表链接；合集可勾选部分条目，单次上限 100 个视频 |
| 抖音链接 | 公开单视频；支持 `v.douyin.com` 短链；平台要求验证时可显式授权 Firefox/Chrome/Edge Cookie；直播和合集不在范围内 |
| YouTube 链接 | 公开、无需登录、单视频、Shorts；需要固定 EJS/Deno 运行时 |
| 本地上传 | 常见音视频格式与 SRT、VTT、ASS、TXT 字幕；文件选择和拖放支持多选，每个文件创建一个任务；音视频单文件最大 8 GiB，字幕单文件最大 16 MiB |
| 本地字幕导入 | 直接规范化为 `transcript.json` 并跳过 ASR；TXT 没有时间轴，作为单段原文导入；可继续生成 AI 笔记与导出原文 |
| 平台字幕 | 发现可用字幕时优先规范化为 `transcript.json` |
| 腾讯云 ASR | 录音文件识别；无 COS 时自适应压缩到内联上限，配置 COS 时支持私有对象中转 |
| 本地 ASR | 用户选择并显式安装固定资产；SenseVoice Small INT8 通过 sherpa-onnx + Silero VAD 在 CPU 转写且不做说话人分离，Faster-Whisper 保留 GPU 与显式 CPU 降级路径 |
| 新总结启动台 | 应用首屏直接提供链接、上传、总结设置和主操作；不增加营销区或重复说明，预检/提交动效可中断并遵守减少动态效果偏好 |
| AI 笔记 | 用户选择笔记且 TokenHub profile 已测试、已授权时调用 `glm-5.1` |
| 内容库 | 展示标题、创建时间、当前阶段、等待云端状态和终态；可进入详情处理失败阶段 |
| 搜索与整理 | 搜索标题、来源、字幕、总结和摘录；按来源、状态、合集、标签和摘录筛选；批量维护合集与标签 |
| 时间戳摘录 | 在字幕行收藏/取消收藏，保存文本快照和个人笔记；搜索结果可直达对应时间点 |
| 校对与回听 | 详情页检索完整字幕；有音频成果时按时间码定位、跟随当前字幕，并可在 0.75×、1×、1.25×、1.5×、2× 间切换速度 |
| 导出 | 音频 M4A/MP3；字幕 SRT/TXT；笔记 Markdown/TXT |
| 部分成果 | failed/canceled 等终态仍可导出已经存在的成果 |

### 3.2 明确不做

- 未经用户授权读取登录态；会员/付费/地区限制内容或 DRM 绕过。
- 硬字幕 OCR、说话人分离、逐字对齐编辑器。
- 多用户账号、云同步、局域网/公网服务。
- 浏览器端直接保存密钥或把用户完整路径展示给前端。
- 自动调用 AI；选择字幕不隐含摘要。

### 3.3 存在代码但未开放的能力

以下内容不是当前 V1 用户承诺：

- 会员/私密内容、抖音合集、YouTube 播放列表、直播和平台硬字幕 OCR；浏览器 Cookie 仅作为公开单视频的平台验证凭据。
- 翻译 stage；新任务界面固定关闭翻译。
- `/setup`、`/settings/storage` 页面；代码存在但当前导航无入口。`/tasks/:id` 已从内容库开放，用于错误解释和阶段重试。
- 阿里云百炼；后端保留兼容实现，当前可见 AI 配置只使用 TokenHub。

这些能力进入产品前必须补齐入口、文案、验收、许可和回归测试，不能仅凭后端代码宣称支持。

## 4. 处理规则

### 4.1 生成选择

浏览器偏好 `vtnote.preferences.v1` 保存默认生成与导出选择：

- 仅音频：创建 `source` 阶段。
- 字幕：创建 `source → transcribe`。
- AI 笔记：创建 `source → transcribe → notes`。
- 音频可以与字幕/笔记同时选择，仅决定是否保留可导出的音频成果。
- 至少选择一种；空或损坏偏好修复为“字幕原文”。
- 没有可用的已授权 AI profile 时，任务降级为字幕，不安排 notes stage。

### 4.2 来源阶段

- URL 必须通过 HTTPS、允许主机、DNS/重定向和资源地址检查。
- 平台有字幕时保存验证后的原始字幕和规范字幕。
- 平台没有字幕时下载音频，进入 ASR。
- 浏览器上传先流式写入受控 incoming 目录，校验后绑定到 task item；Worker 只能在绑定提交后领取任务。
- VtNote 不删除用户选择的原始本地文件。

### 4.3 字幕阶段

- `auto` 模式优先使用当前已测试、已授权的腾讯云 profile。
- 无 COS 时，FFmpeg 根据时长计算 Opus CBR；腾讯官方内联边界按 5,000,000 字节执行，码率计算保留 25% 余量并以转码后的实际字节数最终判定。
- 配置 COS 时，使用广州地域私有 Bucket 和受控对象前缀；终态后安排删除。
- 云端不可用时 `auto` 必须回退用户选择的本地 ASR。本地后备在转 PCM 前检查对应模型、运行时及必要 VAD；若也不可用，必须同时展示云端回退原因与本地错误，不能伪装为完成。
- `transcript.json` 成功发布后不可被同一任务后续阶段覆盖。

### 4.4 笔记阶段

- 只读取规范字幕，不重新下载或重新转写。
- 使用任务创建时冻结的 profile、模型和授权指纹。
- 笔记失败不能删除字幕或音频。
- 输出需要标记 AI 生成并允许用户复核；不把模型输出视为事实来源。

## 5. 状态与恢复

任务由 `source`、`transcribe`、可选 `translate`、可选 `notes` 阶段组成。每个阶段有 attempt、lease、heartbeat、进度、错误和执行证据。

- `queued/running/waiting_external/cancel_requested` 为活动状态。
- `completed/skipped/failed/canceled` 为阶段终态。
- 任务可以是 `completed`、`completed_with_warnings`、`failed` 或 `canceled`。
- Worker 崩溃后回收过期租约，不创建重复的同 attempt 工作。
- 云提交结果未知时不得盲目再次付费提交；重试必须让用户选择本地路径或确认新的云请求。
- 普通 `transcribe` 失败可按原配置重试（仍保留云转本地链路），也可强制仅本地；重试创建新 attempt 并保留历史。
- 内容库只有在音频、字幕或笔记至少一个成果真实完成时才启用导出；失败但无成果时提供“继续处理”，不显示可点击的空导出。

## 6. 数据、隐私与安全

- API 固定监听 `127.0.0.1:8766`，FastAPI 同源提供 React 静态文件。
- 变更请求执行 Host、Origin 和双提交 CSRF 检查。
- 任务、阶段、配置元数据和 runtime 资产索引存 SQLite WAL。
- 规范字幕、译文、笔记和恢复文件在 Data；媒体副本、转码、导出音频和日志在 Cache。
- 密钥在 Windows Credential Manager；SQLite 只存不透明引用。
- 自定义提示词使用当前用户 DPAPI 密文保存。
- “设置 → 模型”提供大文本框编辑总结提示词；首次显示内置模板，修改后自动保存，已有自定义内容按需解密回显且禁止浏览器缓存。
- 日志采用结构化脱敏、5 MiB 轮转和 3 个备份。
- 诊断信息不得包含密钥、原始 provider 响应、完整本地路径或用户文本正文。

详细数据清单见 [技术方案](technical-decisions.md#数据与存储)。

## 7. 非功能需求

| 类别 | 要求 |
|---|---|
| 可恢复性 | API/Worker 任一进程退出后，持久任务不丢失；外部请求状态可继续查询 |
| 原子性 | 规范文件通过 staging/原子发布写入；已完成 transcript 不被替换 |
| 安全 | 路径不能逃逸受控根目录；网络不继承环境代理；密钥和敏感文本 fail closed |
| 可用性 | 375 px 宽度不横向溢出；键盘可操作；进度和错误有文本语义 |
| 性能 | 默认离线测试应在普通开发机约一分钟内完成；页面轮询使用前台/后台不同节奏和失败退避 |
| 成本 | 默认测试不触发真实 ASR/AI；能力验证和真实任务在 UI 中明确可能计费 |
| 兼容性 | 当前发布目标为 Windows；其他平台目录函数存在不等于完整功能已验证 |

## 8. 验收标准

P0：

1. B 站无字幕视频可以进入 ASR，而不会因音频超过内联限制错误回退。
2. 本地大文件上传完成绑定后才被 Worker 领取。
3. 仅选择字幕时任务没有 notes stage，且不调用大模型。
4. 字幕或笔记失败时，内容库仍可导出已有音频；笔记失败时仍可导出字幕。
5. 应用重启后任务、配置和成果仍可读取。
6. 密钥不出现在 API、SQLite 明文字段、日志、任务快照或浏览器 localStorage。
7. 云 ASR 可回退错误与本地模型错误同时可见；失败任务可从内容库进入详情并创建新 attempt 重试。

P1：

1. 取消、租约回收、云端 unknown 和显式重试遵守防重复合同。
2. 回收站恢复只允许原始受控路径尚未被占用的资产。
3. 内容库支持终态任务单条删除、现代文件管理器式区间/组合键选择和批量删除；顶部三态全选开关兼顾全选与取消全部，`Esc`也可清空。批量操作全有或全无，不删除用户本地原始文件，也不丢失云端清理计划。
4. 前端在桌面与窄屏下无严重/关键可访问性问题。
5. 一次选择或拖放多个受支持文件时，每个文件创建独立任务；单个文件失败不重复创建已经成功的任务。
6. 详情页字幕检索覆盖完整结果而不是当前分页；有音频成果时点击时间码可定位播放，无音频时不展示失效播放器。
5. 发布制品通过第三方许可证、FFmpeg 构建和项目 LICENSE 门禁。

完整检查步骤见 [人工验收](VtNote-人工验收测试用例.md) 和 [发布检查表](release-checklist.md)。
