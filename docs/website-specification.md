# VtNote V1 网站规格

状态：可实现规格
Owner：VtNote 产品/前端负责人
下次评审：React 实现计划 Task 5 启动前
证据截止：2026-07-24
需求基线：[product-requirements.md](product-requirements.md)

## 1. 体验目标

V1 网站是运行在 Windows 本机、由 FastAPI 同源提供的 React 工作台。界面应让用户在
一分钟内理解三件事：可以从哪里开始、内容是否会上传、任务失败后下一步做什么。

设计原则：

1. **内容优先**：转录文本、阶段状态和下一步操作优先于装饰。
2. **本地边界可见**：任何云上传之前都显示供应商、授权状态、估算与本地替代方案。
3. **进度诚实**：有可靠分母才显示百分比，否则显示阶段和已耗时。
4. **失败可恢复**：错误与对应输入/阶段相邻，并给出安全的重试、改用本地或设置入口。
5. **紧凑但不拥挤**：适合桌面长时间阅读，核心控件保持至少 44×44 px 可点击区域。
6. **刷新不改变任务**：创建成功后进入可深链详情；刷新只读取持久状态。

## 2. 方案取舍

评估过三种结构：

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 单页长向导 | 首次使用线性清楚 | 历史、设置、重试和深链会挤在一个状态机里 | 不采用 |
| 工作区（创建/历史）、详情、设置三个顶层 surface，多条稳定路由 | URL 清晰、刷新安全、组件边界明确 | 页面之间有少量导航 | **采用** |
| 桌面三栏常驻控制台 | 高密度、适合批处理 | V1 单来源任务过重，小窗和 200% 缩放困难 | Later 再评估 |

采用第二种方案，并让 `/` 与 `/tasks` 同属“工作区”surface，`/setup` 是设置的就绪
状态；任务详情在宽屏内部使用两栏。该取舍与实现计划的三个顶层 surface 一致，不引入
营销首页、账户系统或批量控制台。

## 3. 信息架构与路由

| 路由 | 页面 | 进入条件 | 主要目标 |
|---|---|---|---|
| `/setup` | 首次启动/就绪 | 必需就绪检查未通过，或用户从设置打开 | 解释并修复运行环境 |
| `/` | 创建任务 | 就绪检查允许创建至少一种任务 | 提交 URL、媒体或字幕 |
| `/tasks` | 任务历史 | 始终可访问 | 找到任务、理解聚合状态 |
| `/tasks/:taskId` | 任务详情 | task 存在 | 查看进度、决策、结果、重试/取消 |
| `/settings` | 设置概览 | 始终可访问 | 查看连接、默认项、存储和运行状态 |
| `/settings/connections` | 连接与配置档 | 设置子页 | 新建、测试、授权、归档配置 |
| `/settings/storage` | 存储与回收 | 设置子页 | 查看路径、占用、保留和恢复 |

不存在的 task 返回站内 404，保留“返回历史”按钮。应用使用浏览器 History API；启动器
必须让上述深链都回退到 React 入口，而 `/api/*` 不得回退。

## 4. 应用外壳

### 4.1 桌面布局

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ VtNote              [本地运行 · 就绪]                     [设置]         │
├──────────────┬───────────────────────────────────────────────────────────┤
│ 创建任务      │ 面包屑 / 页面标题                          页面操作       │
│ 任务历史      ├───────────────────────────────────────────────────────────┤
│              │                                                           │
│              │                         主内容                             │
│              │                                                           │
├──────────────┴───────────────────────────────────────────────────────────┤
│ 数据保存在本机 · 版本 · 脱敏诊断入口                                    │
└──────────────────────────────────────────────────────────────────────────┘
```

- 宽度 ≥1024 px 时左侧导航 208 px，主内容最大宽度 1280 px；
- 顶栏只显示产品名、整体就绪状态和设置，不放任务级进度；
- 当前路由同时用背景、左边线和文本标识，不只依赖颜色；
- 提供“跳到主内容”链接，视觉顺序与 Tab 顺序一致。

### 4.2 窄屏与缩放

- 768–1023 px：导航压缩为顶部标签，详情两栏变单栏；
- <768 px 或浏览器 200% 缩放：导航使用可展开菜单，所有主操作保持可见；
- 375 px 下不得横向滚动；长 task ID、URL 和错误码允许断行/复制；
- 表格在窄屏转换为定义列表卡片，不用横向拖动作为唯一查看方式。

## 5. 视觉与交互系统

V1 采用“安静的操作型工作台”，不采用营销页式超大标题、玻璃拟态或持续动画。
`ui-ux-pro-max` 检索建议中的可访问性、键盘、错误邻近、减弱动画和稳定列表键规则被
纳入；其超大字营销版式与远程 Atkinson 字体不适合中文本地工具，故不采用。

### 5.1 字体与密度

- 字体栈：`Segoe UI`, `Microsoft YaHei UI`, `Microsoft YaHei`, system-ui,
  sans-serif；不从公网加载字体；
- 正文 16 px/1.55，辅助文字 14 px/1.5，代码/错误码使用系统等宽字体；
- 可读正文单行建议 65–75 个拉丁字符或相近中文视觉宽度；
- 8 px 间距网格；页面间距 24 px，卡片内边距 16–20 px；
- 标题层级克制：页面标题 28 px，区块标题 20 px，卡片标题 16 px。

### 5.2 颜色令牌

| 语义 | 建议值 | 用途 |
|---|---|---|
| `background` | `#F7F7F5` | 页面底色 |
| `surface` | `#FFFFFF` | 卡片、表单 |
| `text` | `#172033` | 正文 |
| `muted-text` | `#526070` | 辅助文字；仍须达 AA |
| `primary` | `#2457D6` | 主按钮、链接、焦点 |
| `success` | `#157347` | 完成 |
| `warning` | `#9A5B00` | 警告/可能计费 |
| `danger` | `#B42318` | 失败/破坏性确认 |
| `border` | `#D9DEE7` | 分隔 |

实现时必须用实际组件背景验证 WCAG 2.2 AA；状态同时提供文字和图标/形状。V1 只承诺
浅色主题，跟随高对比度/强制颜色模式；深色主题不在范围内。

### 5.3 图标、动效与反馈

- 使用同一套 SVG 线性图标；图标按钮必须有可见 tooltip 和 `aria-label`，不用 emoji
  充当状态图标；
- hover/focus/展开过渡 150–200 ms；不做滚动劫持、视差或装饰性循环动画；
- 遵守 `prefers-reduced-motion: reduce`，此时移除位移和非必要过渡；
- toast 只用于跨页面成功确认；校验、错误、授权和警告必须保留在相关区域；
- 请求中的按钮显示文本“正在…”，保留宽度并禁用重复提交。

## 6. 页面规格

### 6.1 `/setup` 首次启动与就绪

```text
┌─ 欢迎使用 VtNote ──────────────────────────────────────────────────────┐
│ 数据目录      D:\…\VtNote-data                          [可用]          │
│ 运行缓存      D:\…\VtNote-runtime                       [可用]          │
│ FFmpeg        未找到                         [查看安装说明] [重新检查] │
│ 本地模型      尚未下载                       [稍后按需下载]             │
│ 云端/AI       未配置                         [可选，前往设置]           │
│                                                                          │
│                                  [继续使用可用功能]                      │
└──────────────────────────────────────────────────────────────────────────┘
```

行为：

- 首次进入自动检查一次，之后由用户“重新检查”；
- 必需失败与可选缺失分组展示；不得用全屏 spinner 掩盖部分可用能力；
- FFmpeg/数据目录失败时禁用依赖能力并给修复步骤；
- 本地模型未下载不是全局阻塞；首次实际需要时再确认下载；
- 云端/AI 未配置不阻塞 URL 字幕和本地转录。

对应：FR-001、FR-002、NFR-005。

### 6.2 `/` 创建任务

页面由来源、探测/校验结果、处理选项、隐私/费用摘要和提交操作组成。

```text
┌─ 新建任务 ─────────────────────────────────────────────────────────────┐
│ [公开视频链接] [本地媒体] [本地字幕]                                  │
│                                                                          │
│ 视频链接                                                               │
│ [ https://www.bilibili.com/video/...                         ] [探测] │
│ 支持公开的 Bilibili / YouTube；不支持登录、会员或地区受限内容          │
│                                                                          │
│ ┌ 探测结果：标题 · 平台 · 28:13 · 2 条字幕 ┐                           │
│ │ 将优先使用：中文（人工，VTT）           │                           │
│ └───────────────────────────────────────────┘                           │
│                                                                          │
│ 转录：[自动路由 ▼]   翻译 [关闭]   AI 笔记 [开启/配置档]                │
│ [隐私、费用与执行摘要]                                                   │
│                                             [创建任务]                  │
└──────────────────────────────────────────────────────────────────────────┘
```

#### 来源标签

- 切换来源类型会保留同一类型已填内容，但清除其他类型的文件句柄和校验结果；
- 离开有未提交文件的标签前给轻量确认；
- URL 输入接受粘贴后手动探测，不在每个按键自动发网络请求；
- URL 探测成功后，URL 改动立即使旧探测结果失效。
- 字幕预览排除 translated/live track；人工属性未知时显示并排序为“自动/未确认”；
  同组最终按稳定 track ID 决胜，重复探测不得随机换轨。

#### 本地媒体

- 浏览器文件选择显示清理后的文件名、大小、类型和“仅本地/可使用已授权云配置”路由；
- 浏览器不会显示假绝对路径，也不得要求用户复制本机路径；
- 受信本机路径若作为启动器/后端高级入口存在，不在通用浏览器文件控件中混淆展示；
- 上传中显示已传字节/总字节和取消上传；媒体内容校验完成前不允许创建任务。

#### 本地字幕

- 支持 SRT/VTT/ASS/规范 JSON；
- 校验成功显示 cue 数、语言（若可知）、首末时间与编码；
- 无法推断语言时显示“未知”，不凭文件名猜测；
- 字幕输入使 ASR 选项显示“无需执行”，但翻译/笔记仍可配置。

#### 处理选项

- ASR：`自动`、`仅云端`、`仅本地`；没有有效云授权时“仅云端”禁用并链接到授权；
- 没有当前测试成功且已授权的 profile 时，“自动”仍可提交，并明确显示“本任务将
  使用本地转录”；任务快照不得包含失效云 profile；
- 翻译默认关闭；开启后要求目标语言和当前测试成功的配置档；
- 笔记模板固定为“综合总结/干货提炼/自定义提示词”，输出语言默认简体中文；首个
  当前修订 AI 配置档测试成功后笔记一次性默认开启，用户关闭或改语言后不再自动覆盖；
  自定义提示词展开后才显示；
- 高级选项采用渐进披露，不在首屏展示模型内部参数。

#### 隐私、费用与授权

- 摘要始终可见，至少显示“是否上传、供应商、授权修订是否有效、可能计费、可切本地”；
- 对未授权的当前 connection/profile 修订，点击“授权此配置上传音频”打开模态框；
- 模态框列出供应商、base URL/区域提示、模型/资源 ID、会发送的数据、授权失效条件；
- 火山路由摘要同时显示 16 kHz mono OGG/Opus、编码后字节/Base64 估算、语言预检、
  `volc.bigasr.auc_turbo` 与 `model_name=bigmodel`；不显示密钥；
- 用户输入配置名称确认或勾选明确同意后授权；不是每任务重复同意；
- 地址、模型、profile 或 connection 修订变化后授权变为失效，创建页重新提示；
- 任务快照引用授权修订，页面不显示或回传密钥。

#### 内容权利与平台边界

- 在提交动作上方持续显示：“请仅处理你有权访问和处理的内容，并遵守来源平台条款”；
- 提醒不是对登录/会员/地区受限内容的授权，也不暗示平台 adapter 是官方开放 API；
- URL 被拒绝或 direct-only 网络不可达时优先建议使用用户合法持有的本地文件，不提供
  绕过步骤；不把单次 YouTube 超时显示为平台永久不可用；
- V1 底层固定 `trust_env=false`，不继承系统/环境代理，也没有代理设置。UI 不建议
  修改代理环境变量；未来显式可信代理必须在独立 ADR/威胁模型/用户同意后才可出现。

#### 提交

- 仅在来源已探测/校验、选项一致且所需授权有效时启用；
- 点击后按钮变为“正在创建…”，整表单禁止二次提交；
- 成功立即 `replace` 到 `/tasks/:taskId`；失败保留输入并在提交区显示错误；
- 浏览器刷新详情只 GET，不重新 POST。

对应：FR-003 至 FR-010、FR-012、FR-013、NFR-002、NFR-004、NFR-009、NFR-010。

### 6.3 `/tasks` 任务历史

顶部提供状态筛选、来源类型筛选和本地文本搜索；默认按创建时间倒序。

每行/卡片显示：

- 清理后的标题或文件名、平台/输入类型；
- 聚合状态文字和图形、当前阶段或结束时间；
- 创建时间、时长（已知时）、警告数；
- 主要动作“查看”，不在列表直接放危险重试/取消。

交互：

- 整行可聚焦但使用真实链接进入详情，支持中键/新标签；
- 空状态区分“尚无任务”和“筛选无结果”；
- 读取失败保留已有列表并显示内联“重新加载”；
- 超过 100 项时采用分页或虚拟列表，并以稳定 task ID 作 React key；
- V1 不做批量选择、批量取消和批量删除。

对应：FR-005、FR-014、NFR-006、NFR-008。

### 6.4 `/tasks/:taskId` 任务详情

```text
┌─ 标题 / 来源 ───── [复制链接] [取消任务] ──────────────────────────────┐
│ 状态：正在转录 · 已耗时 03:18 · 仅本地                                │
├───────────────────────────┬──────────────────────────────────────────────┤
│ 阶段                      │ [原文] [译文] [笔记] [执行摘要]            │
│ ✓ 来源  原生字幕不可用    │                                              │
│ ● 转录  faster-whisper    │ 00:00  …                                     │
│ ○ 翻译  等待转录          │ 00:08  …                                     │
│ ○ 笔记  等待转录          │                                              │
│                           │                                    [导出]    │
├───────────────────────────┴──────────────────────────────────────────────┤
│ 警告/错误/需要决定：原因、影响、下一步                                 │
└──────────────────────────────────────────────────────────────────────────┘
```

#### 顶部摘要

- 显示聚合状态、输入、路由（本地/云/字幕）、已耗时和警告数；
- 仅非终态显示取消；`cancel_requested` 显示“正在安全停止”且按钮禁用；
- `completed_with_warnings` 首先说明“原文已完成，部分可选结果失败”，避免误判全失败。

#### 阶段面板

- 固定顺序 `source → transcribe → translate / notes`，平行分支视觉上同级；
- 每阶段显示最新 attempt、状态、起止时间和可测进度；
- 展开后显示历史 attempts、稳定错误码、脱敏诊断和结果引用；
- 无可靠百分比时用不循环位移动画的忙碌指示与已耗时；
- `skipped` 必须显示原因，如“已使用上传字幕”或“翻译未启用”。

#### 结果区

- 默认打开原文；虚拟化长 cue 列表，仍允许浏览器查找的替代全文视图/复制全文；
- 替代全文视图不虚拟化，使用语义化连续文本，键盘和屏幕阅读器可完整访问；在 cue
  视图与全文视图切换时保留当前时间位置，并把焦点移到对应稳定锚点；
- cue 行包含可读时间、文本和稳定 cue ID（ID 默认隐藏，可在详情复制）；
- V1 不提供就地编辑；避免让用户误以为修改会回写规范 JSON；
- 译文按同一 cue 对齐；笔记用明确的“AI 生成，请核对”标识；
- 笔记中的时间点显示为可聚焦链接（例如 `12:34`）；点击后切换/定位到原文中对应
  稳定 cue，朗读其时间和文本。无法解析到当前规范转录 cue 的引用不渲染为成功结果；
- 长笔记可展开“来源范围”，显示各顺序分块的首末时间/cue；合并顺序与原文一致；
- 导出菜单区分原文/译文与 JSON/SRT/VTT/TXT/Markdown，不显示不可用组合。

#### 决策与错误面板

| 场景 | 主文案 | 主动作 | 次动作 |
|---|---|---|---|
| 不支持/受限 URL | 无法在 V1 公开访问边界内读取 | 选择本地文件 | 返回创建页 |
| direct-only 网络不可达 | 当前网络无法直连该公开来源；这不是平台永久结论 | 选择本地文件 | 稍后重新探测 |
| 未找到字幕 | 将取得音频并按所选 ASR 路由处理 | 继续当前路由 | 取消 |
| 云授权失效 | 配置已变化，旧上传授权不再有效 | 前往重新授权 | 改用本地 |
| 模型未下载 | 本地模型需要下载到 D 盘 | 查看并下载 | 取消 |
| 火山时长/大小/语言预检不合格 | 尚未上传；自动路由将使用本地，仅云端不能提交 | 使用本地 | 返回修改 |
| 云网络未受理/明确 429 或 5xx | 云服务未完成；自动路由可使用本地 | 使用本地 | 查看状态 |
| 云鉴权/endpoint/resource/model 配置错误 | 云配置需要修复，未以本地结果掩盖 | 前往设置 | 取消 |
| `cloud_outcome_unknown` | 服务端结果未知，可能已计费 | 改用本地 | 检查供应商；显式新云尝试 |
| 核心阶段失败 | 尚无可交付原文 | 重试失败阶段 | 更改设置 |
| 翻译/笔记失败 | 原文可用，此可选结果失败 | 仅重试该分支 | 保留警告 |
| 磁盘不足 | 无法安全发布运行资产 | 打开存储设置 | 取消 |

`cloud_outcome_unknown` 不提供普通“一键重试云端”；显式新云尝试必须二次提示可能重复
计费。错误详情可显示脱敏且限长的 `X-Tt-Logid` 作为供应商支持编号，但不得显示原始
云响应、认证头或音频。

取消合同：

- `cancel_requested` 的重复请求和已经因取消进入 `canceled` 的重复请求返回当前资源；
- `completed|completed_with_warnings|failed` 等其他终态显示为不可取消，并解释原因；
- 当前后端对“已 canceled 后再次取消”的目标合同尚未实现，Task 3/5 集成前必须补测。

#### 轮询与后台状态

- 非终态详情使用自适应轮询；前台间隔、后台退避和允许负载由
  [THR-005](product-requirements.md#threshold-registry) 在 Task 5 client 测试前冻结；
  恢复可见时立即刷新；
- 终态停止轮询；取消、重试等变更成功后立即刷新；
- 一次只允许一个在途轮询，请求慢时不堆积；
- 网络错误使用指数退避并保留最后成功数据，不把网络断开误写成 task 失败；
- 页面卸载时中止未完成 GET。轮询频率须在发布性能测试中复核。

对应：FR-005、FR-011 至 FR-019、NFR-003、NFR-007、NFR-008。

### 6.5 `/settings` 设置

设置概览用四张状态卡进入子区：

1. **运行环境**：FFmpeg、本地模型、GPU/CUDA 探测、版本；CPU 只显示诊断，不承诺
   为 V1 本地 ASR 发布路径；
2. **连接与配置档**：云 ASR、翻译、笔记，显示测试/授权状态；
3. **默认处理**：ASR 模式、翻译、笔记模板；
4. **存储与回收**：路径、占用、24 小时恢复窗口。

#### 连接与配置档

- 连接表单使用持久可见 label，不用 placeholder 代替；
- 密钥字段保存后永不回显；只显示“已保存/未保存”和“替换密钥”；
- URL、协议、用途、模型、options 在字段旁校验；
- “测试连接”结果与当前 connection/profile revision 绑定；
- 测试成功后，云 ASR profile 可单独执行“授权上传”；授权状态与修订同屏；
- 任何相关修改在保存前提示会使测试/上传授权失效；
- 归档前列出默认项与可重试任务引用，不宣称物理删除历史。

#### 默认项

- `auto|cloud|local` 使用单选组，并在 `cloud` 无有效测试+授权时禁用；
- 翻译默认关闭；
- 本地 ASR 卡显示已批准默认
  `large-v3-turbo / int8_float16 / VAD / segment / GPU concurrency=1`，这些值不是
  普通 UI 可静默修改的高级参数；
- 笔记只有当前测试成功的 AI 配置档才能开启；模板固定为“综合总结/干货提炼/自定义
  提示词”，默认简体中文；自动开启规则只执行一次并可被用户永久选择覆盖；
- 保存成功用页内状态和 toast，失败在对应字段与页面摘要同时标识。

#### 存储与回收

- 显示规范化路径，但普通 UI 不允许自由编辑根目录；
- 明确区分“应用管理资产”和“用户原件（永不清理）”；
- 显示占用与最近清理结果，不把估算当精确值；
- 回收列表提供恢复；永久清除需要显示数量/大小并二次确认；
- 当前 V1 若尚未实现永久清除 UI，则只展示 24 小时规则与日志，不做假按钮。

对应：FR-001、FR-002、FR-018、NFR-002、NFR-004。

## 8. 表单校验与文案

### 8.1 校验时机

- 格式类错误在 blur 后显示，提交后显示所有剩余错误；
- 服务端事实（URL 可达、连接有效、媒体可解析）只在用户触发对应动作后判断；
- 服务端错误以机器码映射到本地文案；未知码显示可复制 code 和脱敏诊断入口；
- 用户修正字段后清除该字段旧错误，但不清除无关全局错误。

### 8.2 术语

| 内部值 | 用户文案 |
|---|---|
| `source` | 获取来源 |
| `transcribe` | 生成转录 |
| `translate` | 翻译 |
| `notes` | AI 笔记 |
| `queued` | 等待中 |
| `running` | 处理中 |
| `cancel_requested` | 正在停止 |
| `canceled` | 已取消 |
| `failed` | 失败 |
| `completed` | 已完成 |
| `completed_with_warnings` | 已完成，有警告 |
| `skipped` | 已跳过 |

不要使用“100% 准确”“完全私密”“永久免费”“绝不计费”等无法由 VtNote 控制的承诺。

## 9. 无障碍与键盘

- 每页有唯一 `h1`，标题层级不跳级；
- 导航、表单、标签页、菜单、模态框、表格操作均可键盘完成；
- 自定义 tab 使用 ARIA tab 模式和方向键；不把普通按钮伪装成链接；
- 模态框有焦点圈定与关闭后焦点恢复；无键盘陷阱；
- 动态阶段变化用礼貌 `aria-live` 汇总，不逐条播报轮询噪声；
- 错误摘要链接到具体字段，字段使用 `aria-describedby`；
- 焦点环至少 2 px 且与背景有 3:1 对比；
- 文本/图标与背景达到 AA；正文不低于 16 px；
- 触控/点击目标至少 44×44 px，邻近目标间距至少 8 px；
- 200% 缩放和 375/768/1024/1440 px 视口完成验收；
- 支持 `prefers-reduced-motion`、Windows 高对比度和浏览器缩放，不禁止 zoom。

## 10. 安全与隐私的前端职责

- 前端不得把密钥存入 localStorage、sessionStorage、URL、错误对象或分析事件；
- V1 不加载第三方字体、分析脚本、客服控件或 CDN 运行代码；
- 所有变更请求携带同源会话/CSRF 信息；处理 403 时提示刷新本地会话，不自动重放
  可能有副作用的 POST；
- 外部 URL 显示时去除凭据与敏感查询参数，`target="_blank"` 同时使用安全 rel；
- 普通 task/item/result API 返回用户原件或受信来源绝对路径时视为缺陷；专用
  setup/storage API 可以返回应用管理根目录，且 UI 明确标注“应用管理”，不得与用户
  原件路径混淆；
- 自定义提示词按私密输入处理，不写入浏览器持久存储；
- 下载文件名由服务端提供的安全元数据构造，不直接使用来源标题；
- 页面不声称平台适配器是官方授权接口。
