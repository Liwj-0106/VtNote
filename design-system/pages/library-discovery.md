# 内容库检索与整理页

## 页面目标

让用户在不改变现有“内容库”一级导航的前提下，完成查找、筛选、归类、摘录回看和批量管理。

## 桌面布局

1. 标题栏：左侧“内容库”，右侧保留现有全选/批量操作。
2. 工具栏：一个主搜索框；右侧为筛选、合集、标签三个图标按钮。
3. 作用中条件：只在存在条件时显示紧凑条件胶囊，可逐个移除或一次清空。
4. 结果列表：标题、来源/时间、命中片段或状态、现有操作。字幕命中显示可点击时间码。
5. 选择态：沿用现有陶土色左边标记与浅色背景，不改变行高。

## 搜索行为

- 默认检索标题、规范化来源、字幕正文、总结正文和摘录备注。
- 输入 150ms 后请求；Enter 立即执行，Escape 清空搜索但不清空其他筛选。
- 命中字幕时显示最多两条上下文片段；点击时间码进入详情并定位字幕段。
- 空结果提供“清空条件”单一操作，不显示营销文案。
- URL 保存 `q`、`source`、`status`、`collection`、`tag`，返回页面时恢复查询和滚动位置。

## 整理行为

- 合集为扁平结构，不支持嵌套；标签可多选。
- 单条任务在更多菜单中归类；批量选择后显示合集与标签图标操作。
- 删除合集只删除分类关系，不删除任务；删除标签同理。
- 系统不自动创建标签，也不调用大模型推断分类。

## 摘录行为

- 字幕段右侧提供书签图标；点击立即保存或取消摘录。
- 已摘录字幕允许添加一条纯文本备注，自动保存且不弹成功 Toast。
- 摘录保留任务、字幕段、时间码和源文本快照；源字幕重新生成后标记为“需确认”，不静默迁移。
- `B` 切换当前聚焦字幕段的摘录状态；`N` 聚焦备注。

## 响应式

- 低于 768px：工具栏搜索占满一行，筛选图标放下一行；结果片段最多一条。
- 低于 1024px：隐藏来源文字，仅保留来源图标与可访问名称。
- 所有图标按钮保持至少 40×40px 点击区域。

## 视觉签名

搜索命中的字幕使用“时间码轨道”：等宽时间码位于片段左侧，并用一条 2px 陶土色短线连接正文。它既承担定位功能，也成为内容库增强功能唯一的视觉识别，不添加装饰性插图。
