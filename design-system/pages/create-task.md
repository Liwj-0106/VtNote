# 新总结启动台

## 页面目标

让用户在一个工作台内完成来源选择、输入和开始处理。页面的唯一主要动作是“开始处理”；链接识别、批量选择和上传进度只在需要时出现。

## 视觉方向

- 沿用 `design-system/vtnote/MASTER.md` 的暖中性色、墨色正文和单一陶土色强调，不引入页面专属配色。
- 参考 Refero 中暖纸画布、细边框和单一强调色的组织方式；不采用参考中的多彩卡片、渐变、发光、浮起或弹跳。
- 标题使用现有系统字体，最大 48px。首屏只保留标题，不添加眉题、副标题或操作教学。
- “链接 / 上传”、总结设置和输入区域组成一个有边界的来源工作台，而不是三个分散区块。
- 工作台以 1px 边框和表面明度建立层级；阴影只提供输入区与画布之间的轻微分离。

## 布局

```text
          把音视频变成字幕和笔记

┌──────────────────────────────────────┐
│ [链接] [上传]                  [总结设置] │
├──────────────────────────────────────┤
│ 视频链接、分享文字或本地文件输入区          │
│                                      │
│ [处理状态]               [粘贴] [开始处理] │
└──────────────────────────────────────┘

  错误、合集选择、批量链接或上传进度（按需）
```

- 桌面内容宽度不超过 900px，并与后续按需表面对齐。
- 低于 560px 时总结设置收为图标按钮；处理状态单独占一行，主要动作保持可见。
- 输入控件、按钮和 tabs 的点击区域不低于 44px；键盘顺序与视觉顺序一致。

## 文案

- 标题：`把音视频变成字幕和笔记`。
- 链接 placeholder：`粘贴视频链接或分享文字`。
- 主要动作必须显示文字 `开始处理`，不能只用发送图标表达。
- 键盘行为保留在功能和无障碍语义中，不在 placeholder 或页面正文重复教学。

## 动效

- GSAP 只由 `LauncherSignal` 封装，并且只在 `probing` 或 `submitting` 状态挂载。
- 信号标记先以 `opacity` 与 4px 水平位移进入，状态文字随后以 `opacity` 与 3px 垂直位移进入；不循环、不弹跳、不改变布局尺寸。
- 单次序列控制在 200ms 内。状态变化时旧 timeline 必须清理，不能阻塞提交或导航。
- `prefers-reduced-motion: reduce` 下不创建 timeline，直接显示完整信号和状态文字。
- 不使用 ScrollTrigger、滚动揭示、视差、整页入场、文字拆分或拖拽装饰。

## 校准参考

- Refero Styles：用于比较暖纸表面、边框、字级和单色强调纪律，不直接覆盖 VtNote 的 token。
- 前端交互效果术语手册：采用“状态入场”“短位移淡入”等可描述、可验收的术语。
- GSAP Showcase：只参考 UI 状态反馈的时序；展示型滚动叙事不适用于本地生产力工具。
